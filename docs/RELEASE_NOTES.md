# Notes de version

## Voxirys 0.1 beta

Premiere beta publique de Voxirys pour Windows.

### Telechargements

- Setup Windows recommande : `Voxirys-Setup-0.1-beta-20260606_143947.exe`
- Version portable : `Voxirys-Portable-0.1.zip`
- Empreintes SHA-256 : `CHECKSUMS.txt`

### Fonctions incluses

- Dictee vocale locale.
- Commandes vocales Windows.
- Gestion de la souris a la voix.
- Fonctionnement local sur l'ordinateur.
- Profils de dictee et dictionnaires.

### Confidentialite

- Objectif local-first : voix, commandes et textes dictes restent sur l'ordinateur.
- Aucune donnee vocale ou texte dicte n'est destinee a etre envoyee sur internet pour la dictee locale.

### Compatibilite

- Windows 10
- Windows 11

### Statut

Version beta en developpement. Certaines fonctions peuvent evoluer pendant les prochaines mises a jour.
