# Installation de Voxirys

Voxirys est disponible en installateur Windows et en archive portable.

## Setup Windows recommande

1. Telechargez `Voxirys-Setup-0.1-beta-20260606_143947.exe`.
2. Lancez l'installateur Windows.
3. Ouvrez Voxirys apres installation.
4. Verifiez le micro dans l'application.
5. Testez la dictee, les commandes vocales et la souris a la voix.

Lien direct :
https://github.com/jossmair/Voxirys/raw/main/telechargements/Voxirys-Setup-0.1-beta-20260606_143947.exe

## Version portable

1. Telechargez `Voxirys-Portable-0.1.zip`.
2. Extrayez l'archive dans un dossier local.
3. Lancez Voxirys depuis le dossier extrait.
4. Testez la dictee, les commandes vocales et la souris a la voix.

Lien direct :
https://github.com/jossmair/Voxirys/raw/main/telechargements/Voxirys-Portable-0.1.zip

## Compatibilite

- Windows 10
- Windows 11
