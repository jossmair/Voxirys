# Installation de Voxirys

Voxirys est disponible en version portable et en installateur Windows.

## Version portable

1. Téléchargez `Voxirys-Portable-0.1.zip`.
2. Extrayez l'archive dans un dossier local.
3. Lancez Voxirys depuis le dossier extrait.
4. Testez la dictée, les commandes vocales et la souris à la voix.

Lien direct : https://github.com/jossmair/Voxirys/raw/main/telechargements/Voxirys-Portable-0.1.zip

## Setup Windows

1. Téléchargez le setup depuis la release `v0.1-beta`.
2. Lancez l'installateur Windows.
3. Ouvrez Voxirys après installation.

Lien direct : https://github.com/jossmair/Voxirys/releases/download/v0.1-beta/Voxirys-Setup-0.1-beta-20260603_104635.exe

## Compatibilité

- Windows 10
- Windows 11

## Vérification

Les empreintes SHA-256 sont disponibles dans `CHECKSUMS.txt`.
